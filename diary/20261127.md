# 2026-11-27 flysnake 模型结构与对比

## 当前模型（flysnake）结构

对齐 [fly-brain-snake](https://github.com/SameerV7862/fly-brain-snake) 的用法，再在其上训 MaskablePPO。

```
棋盘状态
  → computeStim（原仓：LC4 looming / sugar GRN L·R / bitter）
  → plastic FlyBrainCore（713 神经元子图，rate-coded 2-step，吃果 → dopamine col_gain）
  → readout rates[7]
  → 拼 obs[15] = rates[7] + sense[5](dS,dL,dR,cross,dot) + habituated deltas[3]
  → MaskablePPO MlpPolicy（pi/vf = [128,128]）→ 动作 0/1/2
```

训练流程：

1. **BC 热启动**：用原仓 `decide(rates, sense)` 作专家标签，对 policy 做交叉熵预训练  
2. **MaskablePPO 精调**：与现有 neuro/CNN 同族超参（lr/clip 线性调度、`gamma=0.94`）  
3. **得分记录**：`MeanScoreCallback` → `mdl/neuro/snake/mean_scores.csv` + TB `rollout/mean_score_*`

| 项 | 值 |
|---|---|
| CLI | `python main.py flysnake re\|tr\|p` |
| 权重 | `mdl/neuro/snake/fly_snake.zip`（本次用 1.9M ckpt） |
| TB | `logs/train/neuro_snake` |
| 观测 | `Box(15,)` float |
| Policy | `MlpPolicy`，可训参数 ≈ 数十 k（浅 MLP） |
| Brain | env 内、plastic、CPU 前向 |
| 训练预算 | 目标 2e6 steps；实际中断于 ~1.92M |
| 评测 mean score（100 局） | **13.92**（max 33） |
| decide 基线 mean | 0.38 |

## 与其他 fly player 对比

| 维度 | flyfixed | flyplastic | flyenc | **flysnake（本方案）** |
|------|----------|------------|--------|------------------------|
| 定位 | 冻 encoder+brain，只训 decoder | 冻 encoder；Hebbian `col_gain` + 训 decoder | 冻 brain；训 CNN encoder+decoder | **对齐原仓 IO + decide BC + PPO** |
| 感官 | 简化手写 stim / 可选冻 CNN | 同左 | 可训 CNN `(84,84,3)→stim[5]` | **原仓 `computeStim`** |
| Brain 位置 | env 内 | env 内 | **policy 内** features extractor | env 内 |
| Brain 可塑性 | 冻结 | Hebbian `col_gain` | 冻结 | **Hebbian `col_gain`** |
| 观测 | rates `[7]` | rates `[7]` | 图像 `(84,84,3)` | **rates+sense+deltas `[15]`** |
| SB3 Policy | `MlpPolicy` | `MlpPolicy` | `CnnPolicy` + `FlyBrainFeaturesExtractor` | `MlpPolicy` |
| 专家 / 先验 | 无 | 无 | 无 | **`decide()` BC 热启动** |
| 训练记分 | 通用 TB reward | 同左 | 同左 | **专用 mean score CSV/TB** |
| @2e6 评测 mean | 0.51 | 0.37 | 0.51 | **13.92**（~1.9M） |
| 相对吞吐 | ~400–500 fps | ~400–500 | **~2900**（env 无脑） | ~800–900（CPU） |

要点：

- 前三套信息瓶颈主要在 **7 维 rates**；flysnake 把 **sense（危险距离/苹果方位）** 直接进观测，PPO 可绕过弱 reward 通路学觅食。  
- flysnake 的 BC 把原仓硬规则变成可微起点；decide 单独玩只有 ~0.4 分，PPO 抬到 ~14。  
- flyenc 吞吐最高，但短预算下未超过固定感官方案。

## 与 CNN PPO（cnnppo）对比

| 维度 | **flysnake** | **cnnppo** |
|------|--------------|------------|
| 观测 | 15 维语义向量（脑读出 + sense） | `(84,84,3)` 棋盘图像 |
| 特征提取 | 无 CNN；依赖 `computeStim` + FlyWire 子图 | SB3 默认 `CnnPolicy` 卷积栈 |
| 中间表示 | 果蝇功能团 rates（可解释） | 隐式卷积特征 |
| 生物学结构 | 有（连接组子图 + dopamine） | 无 |
| Policy | `MlpPolicy` `[128,128]` | `CnnPolicy` |
| 并行 env | 默认 8 | 默认 **32** |
| `n_steps` / `batch` | 1024 / 256 | **2048 / 512** |
| 算法 | MaskablePPO + **decide BC** | MaskablePPO（无 BC） |
| Reward / mask | 复用 `CNNPPOGameEnv` | 同左（同源） |
| 可训规模 | 浅 MLP（小） | 卷积 + MLP（大） |
| 长训效果量级 | mean ≈ **14**（~2e6） | 日记记录长训可达 **60+** |
| 部署成本 | 需带 brain 前向（或蒸馏） | 纯 CNN，推理轻 |
| TB 目录 | `logs/train/neuro_snake` | `logs/train/cnn_ppo` |

要点：

- 二者 **环境动力学与 reward/mask 同源**，差异在「看见什么、怎么决策」。  
- CNN 是端到端像素→动作，上限更高、需更大算力与预算。  
- flysnake 用原仓感官+脑先验换可解释性与样本效率；当前分数仍低于成熟 cnnppo，但远高于早期三套 neuro。

## 结论（一句话）

**flysnake = 原仓 computeStim/decide 管线 + plastic 脑 + sense 增强观测 + BC→PPO**；相对其他 fly player 靠「观测更全 + 专家热启动」把 mean score 从 ~0.5 提到 ~14；相对 cnnppo 仍是小模型/先验路线，分数与吞吐都低于纯 CNN 长训，但结构可解释、可对接 fly-brain-snake。
